# ABZ27 Case Study - Statelessness Elimination

This repository serves as the authoritative source for the specification of the [ABZ27 Case Study](https://abz-conf.org/site/2027/casestudy/), which focuses on the domain of law.

The goal is to use rigorous state-based methods to explore possible instantiations of domestic laws implementing the 1961 UN Convention on the Reduction of Statelessness, and to investigate what guarantees can be provided for effectively reducing or eliminating statelessness.

**Latest version:** [Specification v1.0](specification.pdf)

## Questions/Doubts

To ask for a clarification, general question, or propose further improvements to the document, please file an issue on this GitHub repository. 

Issues will be addressed by the Case Study co-chairs as timely as possible, and regularly be incorporated in the document specification. New document version will be marked as tagged releases of this repository.
